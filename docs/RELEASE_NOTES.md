# Android TV 0.1.0 preview

- Android TV launcher and D-pad navigation using the Max'd branding.
- HTTPS direct video, HLS and DASH playback through Android Media3, with playback controls and track/subtitle selection where supported.
- Independent Android TV stable update feed, version codes, APK verification and user-confirmed Android installation.

This is the Android TV foundation. Nuvio account sign-in, profiles, addon catalogs, library/watch sync, Live TV, media-server browsing and torrents are not implemented yet. Codec, HDR, audio and subtitle compatibility depend on the TV and need physical-device testing.

Development APKs use a separate package/signing identity and cannot upgrade through the stable release channel.
